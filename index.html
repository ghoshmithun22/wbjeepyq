⚡ Physics 📅 WB JEE 2024 📖 Kinematics
A particle moves along x-axis with x = 6t² − 2t³. The particle comes to rest at time t =
A
t = 0 only
B
t = 2 s only
C
t = 0 and t = 2 s ✓
D
t = 1 s only
🤖 AI EXPLANATION • Claude
Step 1: v = dx/dt = 12t − 6t² Step 2: Set v = 0 → 6t(2−t) = 0 Step 3: t = 0 or t = 2 s ✅ Answer: t = 0 and t = 2 s 💡 Tip: Differentiate position → velocity, set to zero!
